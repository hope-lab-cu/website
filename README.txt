HOPE LAB MAIN WEBSITE — GITHUB PAGES
===================================

This package is arranged for the ROOT of the existing repository:
https://github.com/hope-lab-cu/website

Once uploaded and deployed, the live website will be:
https://hope-lab-cu.github.io/website/

The ZIP contains index.html, research.html, publications.html, people.html,
contact.html, and the supporting assets/ directory. All internal paths are
relative and suitable for this GitHub Pages project site.

Design refinements included:
- The authentic HOPE Lab emblem in the header and footer.
- The Bioluminescent Orbit dark teal visual system retained throughout.
- An outlined “Get in touch” header action, matching the reference screenshot.
- A scientific hero photograph with a brighter four-keyword caption.
- Research focus cards with the image LEFT and text RIGHT.
- A Carbon Journal-inspired editorial PI layout.
- Larger body text and improved contrast for comfortable reading.

Before publishing, verify the office hours shown on the Contact page.
