HOPE LAB WEBSITE — COMPLETE UPDATED PACKAGE

This is a complete copy of the website based on the repository ZIP supplied for the 5 November 2026 update. Only the requested homepage publication-link placement and shared footer refinements have been changed.

WHAT CHANGED
1. Homepage: “Explore publications” now appears immediately below the three selected publications, after The FEBS Journal.
2. Footer on all five pages: slightly deeper background/text contrast and modestly larger text, while keeping the existing four-column layout. The Connect column now contains clearly labelled English and Bangla Google Sites links.

HOW TO BACK UP YOUR CURRENT GITHUB WEBSITE FIRST
1. Open https://github.com/hope-lab-cu/website
2. Select the Code tab and make sure the branch is main.
3. Click the green Code button, then select Download ZIP.
4. Save this ZIP somewhere safe. Keep it unchanged as your backup.

HOW TO UPLOAD THIS COMPLETE WEBSITE PACKAGE
1. Extract this update ZIP on your computer.
2. Open the extracted folder. You should see index.html, research.html, publications.html, people.html, contact.html, the assets folder, README.md, and this instruction file directly inside it.
3. In another browser tab, open https://github.com/hope-lab-cu/website.
4. Click Add file, then Upload files.
5. From the extracted folder, select the five HTML files and the complete assets folder, and drag them into GitHub’s upload area. You can also use the file picker to select them. Upload the files/folder themselves, not the ZIP file.
6. Check that the five HTML files are shown at the repository root, and that the assets folder is included. Do not put them inside another folder.
7. In the commit section, keep “Commit directly to the main branch” selected, enter a message such as “Update homepage publication link and footer”, and click Commit changes.
8. Do not delete the existing files before uploading. Matching files will be replaced by the new versions.

IMPORTANT
- index.html must remain at the repository root.
- Keep GitHub Pages configured to deploy from main / (root).
- Do not delete or overwrite repository configuration files that are not in this package, such as CNAME, .gitignore, or .github. If CU ICT has added a CNAME file, preserve it.
- The upload can update the GitHub Pages address before the CU address reflects the changes. Check both after the deployment has updated.
- If GitHub displays an upload or commit error, do not repeatedly click Commit. Take a screenshot of the message and resolve that first.
