HOPE Lab — Design Collection 02 (Upload-ready package)

This is the compact, GitHub-web-upload version of Design Collection 02.
It contains one gallery page and eight independent design folders.
Each design includes five HTML pages (Home, Research, Publications & Preprints, People, Contact) and its own assets folder.
Common illustration/image files are stored once in the shared-assets folder to keep the upload below GitHub's 100-file browser-upload limit.

Upload the entire folder named design-options-round-3 into the ROOT of the hope-lab-cu/website repository.
Do not upload the ZIP file itself. Do not replace the repository-root index.html.
