# HOPE Lab — Eight Original Website Design Concepts

This package contains eight original visual directions created for the HOPE Lab website: four light designs and four dark designs. They are newly developed concepts and are not copies of the example names or styles supplied for the upload workflow.

## Start here
Open `index.html` to see the design gallery. Use the Light / Dark filters and select **Explore complete website** to enter a design.

## Included concepts

### Light
1. Cobalt Journal
2. Terra Forma
3. Paper & Persimmon
4. Cloudline Minimal

### Dark
5. Lumen Circuit
6. Ember Archive
7. Velvet Signal
8. Obsidian Bloom

Each concept is a separate website with Home, Research, People, Publications, News, and Contact pages, plus its own CSS and JavaScript assets. The sites share HOPE Lab's research identity and foundational content so their presentation can be compared consistently.

## GitHub Pages
Upload the entire `hope-lab-eight-original-designs` folder into your repository and commit it. Once GitHub Pages publishes the repository, open `/hope-lab-eight-original-designs/` to view the gallery. Each design is available in its own subfolder.

Before using any concept as the public lab website, replace placeholders with verified staff profiles, publications, news items, and contact details. Google Fonts are loaded from Google Fonts when the site is online.
