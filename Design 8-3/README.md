# HOPE Lab — Website Design Options

This folder contains one gallery page and eight independent website concepts (four light, four dark).

## Preview
Open `index.html` in a browser, or publish this folder through GitHub Pages and visit the `design-options-8/` path on your site. The gallery links to all eight full websites.

Each concept includes six pages: Home, Research, People, Publications, News, and Contact. Each has its own `assets/style.css` and `assets/site.js`.

## Structure

- `index.html` — design gallery and entry page
- `gallery.css` — gallery styles
- `01-editorial-ivory/` through `08-deep-blue-architecture/` — eight separate sites
