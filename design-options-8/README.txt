HOPE LAB — EIGHT DISTINCT WEBSITE DESIGN SYSTEMS

The design-options-8 folder contains a gallery and eight complete preview websites. Each design has Home, Research, Publications & Preprints, People and Contact pages, its own stylesheet, JavaScript and local HOPE Lab logo.

DARK
01 Nocturne Botanical — vertical rail, botanical editorial, serif-led.
02 Carbon Journal — research-journal masthead, condensed type, editorial spread.
03 Pelagic Interface — technical navigation, monospace labels, data-oriented layouts.
04 Velvet Aurora — centered immersive hero, orbital forms, geometric display type.

LIGHT
05 Swiss Type — light Inter-style typography, asymmetrical Swiss grid, cobalt.
06 Fieldnote Botany — field-journal layout, warm paper, folio annotations, serif.
07 White Gallery — exhibition-style visual cards, full-bleed split hero, captions.
08 Architectural Atlas — asymmetric modular composition, mineral palette, structural blocks.

Content is based on the supplied CU HOPE Lab Contents.docx. No publication URLs or profile links have been invented. The abstract diagrams are CSS illustrations rather than original lab photographs.

Upload only the inner design-options-8 folder to the repository root. The gallery is design-options-8/index.html.
