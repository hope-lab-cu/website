HOPE LAB — THREE WEBSITE DESIGN PREVIEWS

THIS IS AN ADD-ON FOLDER. It does not replace the current live website.

EXPECTED DESTINATION IN YOUR GITHUB REPOSITORY:
website/design-previews/

UPLOAD METHOD:
1. Extract the downloaded ZIP on your computer.
2. Open your GitHub repository: https://github.com/hope-lab-cu/website
3. From the repository root, choose Add file > Upload files.
4. In File Explorer, drag the WHOLE folder named "design-previews" (not just the files inside it) into the GitHub upload area.
5. Before committing, verify that the upload list shows paths beginning with:
   design-previews/index.html
   design-previews/gallery.css
   design-previews/01-academic-editorial/index.html
   design-previews/02-midnight-science/index.html
   design-previews/03-modern-institute/index.html
6. Click Commit changes.

DO NOT:
- Upload this ZIP file itself.
- Replace the existing root index.html or other current website files.
- Upload the contents of this folder into the repository root without the design-previews folder.
- Change GitHub Pages settings; the existing main branch / root publishing setting is sufficient.

AFTER COMMIT:
Open https://hope-lab-cu.github.io/website/design-previews/

CONTENTS:
- index.html and gallery.css: the comparison gallery
- 01-academic-editorial: five-page theme 1
- 02-midnight-science: five-page theme 2
- 03-modern-institute: five-page theme 3
- Each theme contains its own assets folder with CSS, JavaScript and logo.

The original website remains at https://hope-lab-cu.github.io/website/ .
