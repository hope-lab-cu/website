UPLOAD INSTRUCTIONS — DESIGN COLLECTION 02 (COMPACT)

WHY THIS VERSION
The earlier package contained 156 files. GitHub's browser upload allows up to 100 files per upload. This rebuilt package contains fewer than 100 files, while keeping all eight designs and all five pages per design.

1. Download HOPE-Lab-Design-Collection-02-upload-ready.zip.
2. Extract it. The extracted folder is named design-options-round-3.
3. Open https://github.com/hope-lab-cu/website
4. Select Add file → Upload files.
5. Drag the WHOLE extracted design-options-round-3 folder into the upload area. Do not drag the ZIP file.
6. Check that all listed paths begin with /design-options-round-3/ and that the page shows fewer than 100 files.
7. Enter commit message: Add HOPE Lab design collection 02 (upload-ready).
8. Select Commit directly to the main branch.
9. Click Commit changes.
10. After GitHub Pages deployment finishes, open:
    https://hope-lab-cu.github.io/website/design-options-round-3/
