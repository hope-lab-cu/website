HOPE Lab Coastal Clarity — updated website package

This package contains the complete five-page website and all required assets.

To replace your GitHub Pages website using the browser:
1. Back up your repository first (Code → Download ZIP).
2. Open https://github.com/hope-lab-cu/website and select the main branch.
3. Choose Add file → Upload files.
4. Extract this ZIP on your computer. Upload the five HTML files and the complete assets folder directly into the repository root.
5. Commit directly to main.
6. Confirm Settings → Pages uses main / (root).

Do not upload this ZIP file itself or place the contents inside another folder.
The published address remains https://hope-lab-cu.github.io/website/
