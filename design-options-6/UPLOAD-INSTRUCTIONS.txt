UPLOAD INSTRUCTIONS — READ BEFORE COMMITTING

1. Extract this ZIP on your computer.
2. Open the extracted folder. It contains one folder named design-options-6.
3. In GitHub, open the HOPE Lab website repository and select Add file > Upload files.
4. Drag ONLY the inner design-options-6 folder into the upload area.
   Do not drag the enclosing ZIP-extraction folder.
5. Before committing, verify that every displayed path begins with:
   /design-options-6/
   Examples:
   /design-options-6/index.html
   /design-options-6/04-forest-observatory/index.html
   /design-options-6/04-forest-observatory/assets/style.css
6. If the path begins with an extra parent folder, cancel the pending upload and select the inner folder.
7. Commit directly to the main branch with summary:
   Add six additional HOPE Lab design concepts
8. Do not delete or replace existing files in the repository.
